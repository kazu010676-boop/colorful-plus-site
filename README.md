# ケアプランセンター カラフルプラス 公式サイト

静岡県浜松市中央区の居宅介護支援事業所「ケアプランセンター カラフルプラス」のホームページです。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | サイト本体（1ページ完結型） |
| `assets/style.css` | デザイン（配色・レイアウト・スマートフォン対応） |
| `assets/favicon.svg` | ブラウザのタブに表示されるアイコン |
| `404.html` | 存在しないページにアクセスされたときの案内 |
| `robots.txt` | 検索エンジン向けの設定 |
| `serve.ps1` | 動作確認用のローカルサーバー（公開対象外） |

## セクション構成

1. トップ（キャッチコピー・電話番号）
2. カラフルプラスの名前の由来（シンボルツリー）
3. ICTをフル活用した、速く・正確な連携
4. こんなときは、私たちにご相談ください
5. サービス内容（ケアマネジメント業務）
6. ご利用の流れ（6ステップ）
7. 費用について
8. 専門職の方へ（ご紹介・連携）
9. 事業所概要・アクセス
10. お問い合わせ・個人情報の取扱い

## よくある修正のしかた

すべて `index.html` をメモ帳等で開いて、該当する文字を書き換えるだけで反映されます。

- **電話番号を変える**：`090-8504-0458` を検索して置き換えます。`tel:09085040458` の部分（ハイフンなし）も忘れずに置き換えてください。
- **受付時間を変える**：`8:30` `17:30` を検索して置き換えます。
- **住所を変える**：`向宿1丁目7-3` を検索して置き換えます。地図の `src` に含まれる住所も更新が必要です。
- **文章を直す**：該当する日本語をそのまま探して書き換えます。`<` と `>` で囲まれた部分（タグ）は消さないでください。

保存後、GitHubに反映すると数十秒で公開サイトに反映されます。

## 動作確認（ローカル）

PowerShell で以下を実行し、ブラウザで `http://localhost:8080` を開きます。

    powershell -ExecutionPolicy Bypass -File serve.ps1

## 掲載内容に関する注意

介護保険法および景品表示法により、事実と異なる表示・誇大な表示は禁止されています。
サービス内容や体制を変更した際は、本サイトの記載も速やかに更新してください。
